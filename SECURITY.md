# Security Policy

## Supported Versions

Only the latest release on the `main` branch is actively supported with security and game-update fixes.

## Reporting a Vulnerability

If you discover a security vulnerability (such as a server crash exploit, remote code execution, or privilege escalation) in **GameFixes_mm**, please **do not** open a public GitHub issue.

Instead, report it privately to the maintainers (**SyntX** and **Denied**) via the Nova Zombie Community channels or GitHub private security advisory. Include:
- A description of the issue and potential impact
- Steps to reproduce or a minimal proof of concept
- Affected OS (Linux, Windows, or both)
